WHAT IS A CTF

Capture The Flag

CTF stands for "Capture The Flag." Since cybersecurity can be theory-heavy, CTFs were created to gamify the learning experience. Rather than reading textbooks, you solve hacking puzzles — and the reward for solving each one is a flag: a special string you submit to prove you cracked the challenge.

flag
What a flag looks like

Every challenge hides a flag — a text string in a specific format. You find it, you submit it, you get points. It usually looks like this:

picoCTF{y0u_f0und_the_secret_123}

Challenges come in many forms: a file to analyze, a website to hack, ciphertext to decode, or a binary to reverse. Each domain has its own style — all explained below.

LINUX SETUP

Set Up Linux First

Almost all CTF tools are built for Linux. It's highly recommended you have a Linux environment before starting. You can set it up in multiple ways — pick whichever suits your system:

VM

Virtual Machine (Recommended for beginners)

Run Linux inside your existing OS using VirtualBox — no risk to your main system. Follow the video for your OS below.

DB

Dual Boot

Install Linux alongside Windows/Mac and choose which OS to boot into at startup. Gives full performance but requires disk partitioning.

WSL

WSL (Windows Only)

Windows Subsystem for Linux — run a Linux terminal directly inside Windows without a VM. Quick to set up but some tools may not work fully.

04
LEARNING STRATEGY

How You'll Actually Learn

In CTFs you learn by solving — you'll pick up new tools while working through challenges, not before. So just start: watch a tutorial, ask AI, and look for challenge writeups. A writeup is the solution someone publishes after solving a challenge. You read it, understand it, then try to replicate it yourself. You'll also be required to write your own writeups for recCTF — the EHAX recruitment CTF (more on that below).

If you don't know how to solve a challenge, read its writeup. If it mentions a tool you don't know about, learn how that tool works with a quick YouTube video, then come back and retry the challenge. You can also ask anything in the group — your seniors are always there to help. Don't be shy to ask or discuss; showing interest and actually going through problems is exactly what gets you noticed, and it earns brownie points for recruitment.

Advanced — do after REV ☠️
